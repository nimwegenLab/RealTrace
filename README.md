# RealTrace

RealTrace is an algorithm to rigorously infer the cell dynamics from noisy time lapse microscopy data, which is described in this [paper](https://www.biorxiv.org/content/10.1101/2025.09.12.675772v1.abstract).

 ____


For a quick start, check out the [RealTrace tutorial](https://github.com/nimwegenLab/RealTrace/tree/main/RealTrace_Tutorial). You can use is to run a provided example data set yourself or use it as a step-by-step guide.

The [Wiki](https://github.com/nimwegenLab/RealTrace/wiki) describes the usage of RealTrace in more detail.
